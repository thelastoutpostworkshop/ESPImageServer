## How to try an example

1. Open **Generate image** or **Generate video** and select the model listed for the example. A model downloads on first use; generation requires a supported NVIDIA GPU.
2. Copy the **Prompt** into the description field. Copy the **Negative prompt** into the optional field describing what the image or video should avoid. All models represented here support negative prompts. When the entry says **None**, leave that field empty; do not paste the word `None`.
3. Set **Generation steps** and **Seed** to the recorded values. Turn off **Use a new random seed for every image/video** to keep the supplied seed, or turn it on to explore variations.
4. Use the recorded orientation and rotation as a guide for composition. The dimensions describe the original output; adapt the example to your selected display. **Not recorded** means the export did not contain an orientation, so choose one that suits the scene.
5. Select **Generate image** or **Generate video**.

The export does not include video duration, frame count, frames per second, or any source image used as the first frame. Choose a short duration and your preferred frame rate when trying a video. For LTX prompts that refer to an existing scene, you can generate a suitable image, save it to your Creation Library, and select it as the first frame. Wan uses text only.

These are starting points for your own creations. The same prompt and seed do not guarantee an identical result when the model, dimensions, other settings, or software differ.
